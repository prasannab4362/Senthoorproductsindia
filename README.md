# NATIVE NATURE

Responsive static website for Senthoor Foods India. No build or runtime dependencies.

Run `npm run dev` and visit http://127.0.0.1:4173. Run `npm run check` for JavaScript syntax validation. Deploy the `dist` directory to a static host.

## Content and enquiries

The seven collections reflect the ingredient families supplied by the business. Exact manufactured products, pack sizes, certifications, contact details and shipping arrangements have not been supplied, so the website does not invent them. The enquiry form validates fields and downloads a text enquiry locally. It does not transmit or store enquiries. Replace this flow with a real contact destination or backend when details are available.

The hero is AI-generated editorial ingredient imagery, not a photograph of the company's products or facility. Ingredient illustrations are inline SVG. Fonts use Google Fonts with system fallbacks.

## Editing

- `dist/index.html`: page content and enquiry form
- `dist/styles.css`: visual design and responsive layouts
- `dist/app.js`: collections, filters, dialogs, mobile navigation and enquiry download
- `dist/assets/`: logo mark and hero image

## Image generation

Built-in image-generation tool. Prompt: Premium Indian food brand editorial still life on warm ivory plaster: whole and cut jackfruit, ripe small bananas, cashews, groundnuts, bowl of rice and deep green banana leaves. Warm morning sunlight, tactile textures, central portrait composition, forest green and butter-yellow palette; no text, logo, packages or watermarks. Illustrative ingredients, not actual manufactured products.
